The code

The listing reassembles byte for byte with make verify: the 32 banks give back the whole ROM. Everything is explained (code, or data with whoever reads it) and 42.7 % of the instructions carry a comment; no routine is below 10 % and there is no call to an unnamed routine.

How it is made

  • tools/bancos.py traces the whole cartridge keeping track of which bank sits in each window; the entries of each bank come from there.
  • tools/anotaciones.py holds the names of the routines, the RAM and the records (character, actors, objects, projectiles, sound channels).
  • src/pNN.notes: the hand notes for each bank.

Code shared with other Konami cartridges

This disassembly has been compared, instruction by instruction, with every other Konami one in the series. A block counts when the same instructions, at least six of them from a label to its ret or its unconditional jump, are in both cartridges; the addresses are left aside, because they change from one cartridge to the next.
